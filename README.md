# PreventX – Multi-Disease Prediction System

## 📌 About the Project

PreventX is a Machine Learning based healthcare application that helps predict different diseases based on user-provided medical information and symptoms.

## 🚀 Features

- 🩺 Disease prediction using Machine Learning
- ❤️ Heart disease prediction
- 🩸 Diabetes prediction
- 📊 Easy-to-use Streamlit interface
- 🤖 Machine Learning based predictions
- 📋 Displays prediction results clearly

## 🛠️ Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

Clone the repository.
Open the project folder in VS Code.
Install the required libraries:
pip install -r requirements.txt
Run the Streamlit application:
streamlit run app/app.py
